# 🎵 Sistema Musical em HTML

Um player/sistema de áudio web interativo e responsivo desenvolvido com tecnologias front-end fundamentais (**HTML5**  e **CSS3**).

---

## 📌 Sobre o Projeto

O **Sistema Musical em HTML** é uma aplicação desenvolvida para demonstrar a reprodução e controle de áudio diretamente no navegador. O projeto aplica conceitos práticos de manipulação do DOM, controle de elementos de mídia via JavaScript e estilização de interfaces modernas.

Projetado por **Gabriel Martins Mandelli** no âmbito dos estudos no **SENAI Jacob Lafer**.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e tags nativas de mídia (`<audio>`).
* **CSS3:** Estilização visual, layout responsivo e efeitos visuais.
* **JavaScript (ES6+):** Lógica do player (play/pause, progresso, volume, troca de faixas) e manipulação dinâmica da interface.

---

## ✨ Funcionalidades

* ⏯️ **Controles de Reprodução:** Reproduzir, pausar, avançar e retroceder faixas.
* 🔊 **Ajuste de Som e Progresso:** Controle de volume e barra interativa para navegar na música.
* 📜 **Gerenciamento de Playlist:** Alternância simples entre diferentes faixas de áudio.
* 📱 **Layout Responsivo:** Adaptável a telas de desktop e dispositivos móveis.
